## Indic Language Technology

Resources for building language tools, finding datasets, and exploring models for languages of the Indian subcontinent.

### Catalogs & Toolkits

- [Indic NLP Catalog](https://github.com/AI4Bharat/indicnlp_catalog) - Community-maintained pointers to Indic-language NLP datasets, models, and other resources.
- [Bhashini ULCA](https://bhashini.gov.in/ulca) - Platform for discovering and sharing Indian-language datasets, models, and language technology APIs.
- [Indic NLP Library](https://github.com/anoopkunchukuttan/indic_nlp_library) - Python utilities for Indic text normalization, tokenization, script conversion, and related NLP tasks.

### Models & Datasets

- [IndicTrans2](https://github.com/AI4Bharat/IndicTrans2) - Open multilingual machine-translation models, datasets, and evaluation resources for Indic languages.
- [IndicXlit](https://github.com/AI4Bharat/IndicXlit) - Transliteration models for converting between Roman and native scripts across Indic languages.
- [IndicBERT](https://github.com/AI4Bharat/IndicBERT) - Indic-language pretrained models, corpora, and language-understanding benchmarks.
- [IndicTTS](https://github.com/AI4Bharat/indic-tts) - Open text-to-speech research and models for multiple Indian languages.
- [Dakshina Dataset](https://github.com/google-research-datasets/dakshina) - Google Research dataset for language and script work, including native-script text and romanization resources.

## 3D Web Portfolios

Examples and galleries for studying how 3D scenes, motion, and interaction can support a portfolio or creative studio website.

### Examples & Inspiration

- [Bruno Simon](https://bruno-simon.com/) - Playful, drivable 3D portfolio that turns the site into an interactive world.
- [Lusion](https://lusion.co/) - Creative studio portfolio showcasing polished, interactive 3D web experiences.
- [Awwwards: Three.js websites](https://www.awwwards.com/websites/three-js/) - Gallery for discovering websites recognized for their use of Three.js.

## Three.js for Beginners

Start with the fundamentals, then use the official references and examples to build small scenes before adding frameworks or complex assets.

### Tutorials & References

- [Three.js Manual](https://threejs.org/manual/) - Official step-by-step guides to the core concepts and common workflows.
- [Three.js Documentation](https://threejs.org/docs/) - Official API reference for the library.
- [Three.js Examples](https://threejs.org/examples/) - Official interactive examples with source code for exploring features and techniques.
- [Discover three.js](https://discoverthreejs.com/) - Free, detailed introduction to building 3D applications for the web with Three.js.
- [Three.js Journey](https://threejs-journey.com/) - Structured, project-based video course; some introductory material is available for free.

### Libraries & Tools

- [Three.js](https://github.com/mrdoob/three.js/) - JavaScript 3D library for creating scenes rendered in the browser.
- [React Three Fiber](https://github.com/pmndrs/react-three-fiber) - React renderer for Three.js, for building scenes with React components.
- [Drei](https://github.com/pmndrs/drei) - Useful helpers and abstractions for React Three Fiber projects.
- [gltfjsx](https://github.com/pmndrs/gltfjsx) - Converts GLTF 3D models into reusable React Three Fiber components.
