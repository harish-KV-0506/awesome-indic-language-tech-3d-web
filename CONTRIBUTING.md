# Contributing

Thanks for helping improve this curated list. The goal is to recommend useful, relevant resources—not to collect every link on the topic.

## Suggest a resource

1. Open a pull request with one resource per entry.
2. Use its canonical URL and place it in the most relevant existing category.
3. Add a concise, factual description that explains what the resource offers.
4. Check that the link works and avoid duplicates, link shorteners, affiliate links, and purely promotional entries.
5. Only recommend resources you have used or can confidently vouch for. Do not claim that a project is maintained or supports specific languages unless you have checked.

If no current category fits, explain the proposed category in your pull request. The list is intentionally curated; a smaller set of useful resources is better than an unreviewed link dump.
